## 1. `dashboard.devtools`

صفحة HTML بعنوان «الصفحة الرئيسية». تضع `#app` وتحمّل JS بنمط `defer` من `/js/chunk-vendors.1b093cc7.js` و`/js/chunk-common.ddcf658a.js` و`/js/employee.21e9f881.js`، بالإضافة إلى CSS الثلاثة. الامتداد `.devtools` لا يعني تسجيل Network أو Chrome DevTools؛ المحتوى HTML. لوحظت `/>/>` زائدة قرب أيقونة الصفحة، وهذا خلل markup بسيط يتسامح معه المتصفح غالبًا. لا توجد بيانات دخول مثبتة داخل الصفحة.

## 2. `chunk-vendors.1b093cc7.js`

حزمة كبيرة ضمن `self.webpackChunkDMS`. تحتوي تعريفات مكتبات Vue.js **2.6.14** وvue-router **3.5.2** وVuex **3.6.2** وjQuery **3.6.0** وBootstrap JS **4.6.1** وSweetAlert2 **11.7.3** وAxios، إضافة إلى مكتبات لمسح وتوليد QR ومكونات UI. العبارة `jQuery v1.9.1` داخل الحزمة **شرط الحد الأدنى المقبول لدى Bootstrap وليست رقم نسخة jQuery المستخدمة**؛ النسخة المدمجة فعلًا 3.6.0.

**تقادم الدعم:** وفق موقع Vue الرسمي، Vue 2 انتهى دعمه في 31 ديسمبر 2023: https://v2.vuejs.org/eol/ . هذا خطر صيانة ودعم أمني وليس إثبات ثغرة CVE محددة.

**سلوك مشروط داخل SweetAlert2:** إذا كانت لغة المتصفح روسية ويقع الموقع على نطاق `.ru` أو `.su` أو `.xn--p1ai`، وبعد فترة مرتبطة بقيمة `localStorage["swal-initiation"]`، يوجد فرع يضبط `document.body.style.pointerEvents="none"` ويشغّل صوتًا من نطاق خارجي. لا ينطبق شرط نطاق الموقع على `dm.ur.gov.iq`؛ ولم تثبت أي عملية إرسال بيانات أو تنفيذ هذا الفرع على النظام العراقي. يفضّل مراجعة المكتبة المجمّعة وتحديثها ضمن سياسة التبعيات.

تحتوي الحزمة أيضًا على `new Function(...)` ضمن معالجة عناصر `swal-function-param`، وعلى أنماط `eval`/`innerHTML` ضمن المكتبات؛ لا يعني وجودها وحده وجود XSS دون مسار إدخال غير موثوق.

## 3. `employee.21e9f881.js`

نقطة دخول لوحة الموظفين؛ تعرف Vue Router بوضع `history` مع أساس `/employee/dashboard/`. يوجد **49 تعريف مسار** يحمل `meta.requiresAuth`، منها مستندات ومجلدات وصلاحيات وسجل حركات ومستخدمون وتقارير وQR. حارس التنقل يختبر `getters.token` في Vuex. **هذا قيد عرض وانتقال داخل المتصفح، ولا يثبت صحة فرض الصلاحيات من الخادم**.

رُصدت **58 معرّفات أجزاء ديناميكية** تطلبها عمليات التحميل الكسول `a.e(...)`؛ هذه الأجزاء ليست ضمن الملفات الثمانية، ولذلك لا يمكن إعادة بناء التطبيق بالكامل من هذه الدفعة وحدها.

### ملاحظة A — نقل بيانات داخل URL وConsole (أولوية مرتفعة، أثر مشروط)

طريقة `opendm()` تطبع `this.user.userRedirect` و`this.user.passRedirect` إلى Console، ثم تفتح مسارًا على ODM يحتوي query باسم `su1` و`su2` مأخوذين من الحقلين. إذا كان `passRedirect` يمثل كلمة مرور/رمز جلسة فعلًا، فإن وضعه في URL قد يكشفه في سجلات المتصفح أو الخادم أو قنوات الإحالة. **لم يثبت نوع المحتوى الفعلي للحقل** في هذه الشيفرة. ينبغي عدم طباعة قيم حساسة، واستبدال تمرير الاعتماد في URL بتبادل جلسة قصير العمر وخادمي.

### ملاحظة B — أدوار الواجهة (متوسطة)

تعرض القائمة عناصر مختلفة تبعًا إلى `isOrgAdmin` و`usHaveReadOnly` و`role`. هذه فلاتر لواجهة المستخدم فقط؛ تحقق الخادم من RBAC غير موجود في الحزمة المرفقة. لا يجوز اعتبار تغيير قيمة محلية برهانًا على تجاوز صلاحيات.

### ملاحظة C — `isLoggedIn` والتسجيل (منخفضة)

يكتب `opendm()` القيمة `true` داخل `localStorage.isLoggedIn`، وهي حالة عميل وليست إثبات مصادقة. كما تُستدعى واجهة `Endpoint/UsersOnlineCount` دوريًا خلال عمل الصفحة. يفيد التأكد من إيقاف المؤقت عند إزالة المكون.

## 4. `chunk-common.ddcf658a.js`

يعرّف إعدادات `VUE_APP_API_URL=https://dm.ur.gov.iq/api/`، و`VUE_APP_CLIENT_ID=202`، وروابط `ReadQrWithUR` وODM وUR. **العدد 202 معرّف عميل ظاهر للمتصفح وليس كلمة مرور أو سرًا بحسب الشيفرة**.

### ملاحظة D — معالج أخطاء Axios (متوسطة)

معالج الاستجابات يفحص مباشرة `e.response.status` و`e.response.data.message`. عند خطأ شبكة بلا `response` قد يرمي `TypeError` ويخفي المشكلة الأصلية. الإصلاح: `const status = error.response?.status` والتعامل مستقلًا مع أخطاء الشبكة والمهل الزمنية.

### ملاحظة E — جلسة/CSRF (متوسطة بحاجة تحقق خادمي)

يرسل `User/Logout` بطلب GET وباسم ترويسة `Token`. وتهيّئ الحزمة `X-CSRF-TOKEN` في POST من `getters.token` أو `getters.csrfToken`. ينبغي مراجعة فصل Token المصادقة عن CSRF وتفضيل عملية خروج غير قابلة للاستدعاء عَرَضًا عبر GET إذا كانت تغيّر حالة الخادم. لا يمكن إثبات ضعف CSRF من الواجهة وحدها.

### ملاحظة F — رابط أداة المسح (منخفضة)

القيمة `VUE_APP_SCANNER` تحتوي `https:/dm.ur.gov.iq/...` بشرطة `/` واحدة بعد `https:`. هذا رابط غير قياسي على الأرجح وقد يؤدي إلى فشل التنزيل أو اعتماد حلّ عنوان نسبي حسب السياق. المسار `NDC_Scanner.msi` برنامج Windows خارجي غير مرفق؛ لم يُنزّل أو يُنفّذ.

## 5. `chunk-vendors.7ac31ae5.css`

حزمة CSS بحجم 322,978 بايت؛ تتضمن `vue-treeselect v0.4.0` وتعليقات تشير إلى كل من Bootstrap CSS **v4.6.1** و**v4.3.1**. تكرار إطار CSS بإصدارين قد يؤدي إلى تعارضات cascade وأحجام أكبر، لكنه ليس ثغرة أمنية مثبتة. رصدت نحو 4,069 إغلاق قاعدة CSS و127 توجيه `@media` في النص.

## 6. `chunk-common.04b3f60d.css`

أنماط استجابة الشاشة للقوائم والهيدر والفوتر، بالإضافة إلى Font Awesome **4.7.0** ومرجع خطوط `/fonts/fontawesome-webfont.*`. يعتمد المظهر على أصول خط خارج الملفات الثمانية. لا توجد آلية مصادقة أو رمز جلسة في ملف CSS.

## 7. `employee.600a28b0.css`

أنماط لوحة تحكم الموظف: sidebar وfooter والعلامات المائية والتحكم في العرض، وخط Almarai بمراجع `/fonts/almarai-v5-arabic-regular.*`. أبرز الألوان المستخدمة تشمل `#dc3545` و`#043b81` و`#1771b5`. توجد قاعدة نهائية `Swal .confirmButtonColor` قد لا تطابق العنصر المراد، إضافة إلى علامات تنصيص حول قيمة لون CSS؛ هذا احتمال خلل تنسيق وليس خطرًا أمنيًا.

## 8. `config.xlaunch`

ملف XML لإعداد XLaunch على Windows، منفصل عن واجهة DMS. يُظهر `ClientMode=NoClient` و`WindowMode=Windowed` و`Clipboard=True` و`Wgl=True` و`DisableAC=True`. **تعطيل Access Control** يستحق المراجعة إذا كان خادم X11 متاحًا لمستخدمين أو أجهزة أخرى، لأنه قد يسمح بالوصول إلى جلسة العرض عند غياب قيود شبكة مناسبة. لا يحتوي الملف على كلمة مرور أو مفتاح خاص، وحقل `RemoteHost` فارغ. لا يوجد دليل على أنه قيد التشغيل أو معرّض للإنترنت.

## فرز أولويات التحقق

| الملاحظة | أولوية مراجعة | الثقة وحدود الاستنتاج |
|---|---|---|
| `passRedirect` في Console ورابط `su2` | مرتفعة | نمط مثبت؛ حساسية قيمة الحقل لم تُثبت |
| `e.response.status` بلا حماية | متوسطة | خطأ محتمل مثبت عند network error |
| استخدام Vue 2 المنتهي الدعم | متوسطة | نسخة وإعلان انتهاء الدعم مثبتان |
| XLaunch `DisableAC=True` | متوسطة مشروطة | الإعداد مثبت؛ التعرض الشبكي غير معروف |
| فصل Token وCSRF وطلب Logout | متوسطة | تصميم ظاهر؛ حماية الخادم غير معروفة |
| SweetAlert2 وفرع خاص بالنطاق الروسي | منخفضة على النطاق العراقي | شرط واضح، لا يطابق نطاق `.iq` |
| Bootstrap CSS 4.3.1 و4.6.1 | منخفضة | احتمال تعارض واجهة |
| خطأ `https:/` في رابط scanner | منخفضة | خلل نصي ظاهر، لم يُختبر التنزيل |

## فحص البيانات الحساسة

لم تُكتشف سلسلة JWT كاملة أو مفتاح خاص PEM أو `ghp_`/`sk-proj-` أو Bearer Token ثابت من الأنماط التي فُحصت. **هذا لا ينفي وجود بيانات حساسة مضمّنة بصيغ أخرى**. وجود `passRedirect` وقيم URL ديناميكية هو سبب مستقل للمراجعة.
