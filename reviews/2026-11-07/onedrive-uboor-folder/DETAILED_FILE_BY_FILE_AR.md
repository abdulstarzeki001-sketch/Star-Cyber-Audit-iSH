**طريقة العمل:** قراءة الملفات المحفوظة في OneDrive دون تشغيل JavaScript أو اختبار خوادم حكومية. فحص أسماء ومسارات الربط وعناصر النماذج والبيانات الشخصية، ثم مقارنة الأصول المشار إليها بأسماء الملفات المحفوظة في GitHub.

## الجرد

- المجلد الأصلي: `customs-uboor.ur.gov.iq+_1772003025841`.
- فرع `customs-uboor.ur.gov.iq`: **6 صفحات/ملفات HTML + صورتا PNG**.
- فرع `ur.gov.iq/js`: **فارغ** في الجرد الحالي.
- **النسخ الموجودة داخل GitHub العام:** ستة ملفات HTML منقّحة بصيغة `.html.txt` وأسماء لا تتضمن رموزًا أو أرقام هواتف. صورتا PNG موجودتان في OneDrive ولم تُنقلا كملفات ثنائية إلى GitHub حتى الآن. ملفا وصف المصدر `.png.source.md` لا يعوّضان الصورة الأصلية.
- لا توجد ملفات JS/CSS فعلية ضمن الثمانية. أسماء المكتبات التي تظهر في HTML هي **إشارات إلى ملفات مطلوبة** وليست محتوى موجودًا داخل هذا المجلد.

## 3 — واجهة صاحب الشركة: `company-owner/index.html`

- **الحجم الأصلي:** 21,241 بايت.
- **النوع:** HTML عربي RTL بعنوان «بوابة أصحاب الشركات».
- **المحتوى:** بطاقة بوابة صاحب الشركة وواجهة البحث باستخدام «كود الشركة (Hash Code)» المرسل عبر SMS، مع عرض بيانات هوية واتصال في اللقطة الأصلية.
- **التبعيات:** `index-ccmhdhtn.js`، و`companyownerview-cjdszkn6.js`، و`card-cxdtecyo.js`، و`badge-ddrqdsta.js`، و`form-ldzoexkp.js` وغيرها من مكونات Vite. بعض الأسماء موجودة بالفعل في أرشيف GitHub السابق، والبعض الآخر مفقود من هذا المجلد والمستودع بالاسم نفسه.
- **الملاحظة الأمنية:** حقل Hash Code في HTML لا يثبت آلية التحقق الخادمِي أو مدة صلاحية رمز SMS. تحتوي النسخة الأصلية بيانات اسم واتصال، وقد حجبت عن النسخة العامة.
- **حالة الأرشفة:** [نسخة منقّحة](../../research/onedrive-uboor-capture/2026-11-07/customs-uboor.ur.gov.iq/company-owner/index.html.txt).

## ما ينقص لتشغيل اللقطات كتطبيق

أهم الأصول المطلوبة المشار إليها من HTML وغير الموجودة في هذا المجلد هي:
`index-cseaomal.js` و`index-ccmhdhtn.js` و`index-iqgxgunl.css` و`card-cxdtecyo.js` و`table-dtmqfnp9.js` و`schemas-b4dorvt-.js` و`textarea-bgo3bjb3.js` و`form-ldzoexkp.js`. وبذلك لن تعمل نسخة مستقلة كاملة اعتمادًا على هذه الملفات الثمانية فقط. كما أن وجود ملف JS محفوظ ببناء آخر لا يثبت أنه متوافق مع HTML هنا.

## خلاصة المخاطر والقيود

1. **حساسية البيانات:** بعض الملفات تحتوي قيم QR ورقم هاتف واسم ومعلومات اتصال داخل النسخة الخام أو اسم الملف. لا يجوز تحويل المستودع العام إلى أرشيف مفتوح لهذه البيانات.
2. **سياق التحليل:** جميع الاستنتاجات مبنية على لقطات ثابتة؛ لم تُختبر خوادم الحكومة أو تُصدر وثيقة أو تُفحص صلاحية QR.
3. **تغطية الملفات:** 6/6 HTML محفوظة بنسخ منقّحة، و2/2 PNG موثقتان لكن لم تُرفعا كملفات أصلية. ومجلد `ur.gov.iq/js` خالٍ من الملفات.
4. **حالة النسخة العامة:** ملفات `.html.txt` للعرض والمراجعة، وليست واجهة حكومية صالحة للنشر والعمل.

**قرار النشر:** نشر التحليل والفهرس والنسخ النصية المنقّحة، مع الاحتفاظ بالصور الخام وأسماء الملفات الحساسة داخل OneDrive. يمكن نقل الصور الثنائية إلى GitHub عند توافر طريقة نقل ناجحة؛ لا يمكن اعتبار هذا النقل قد حدث قبل التحقق من البايتات في GitHub.
