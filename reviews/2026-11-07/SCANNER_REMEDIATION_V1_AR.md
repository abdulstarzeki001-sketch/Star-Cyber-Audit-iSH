# تقرير تنفيذ الإصلاحات — Star Cyber Audit Analyzer

**التاريخ:** 7 نوفمبر 2026  
**الإصدار:** Scanner remediation v1  
**المستهدف:** كود محلل المصادر الخاص بالمشروع (`analyze.py` + `tests/test_audit.py` + CI)، وليس الأنظمة الحكومية.

## الإصلاحات التي نُفذت

| المرجع السابق | المشكلة | الحالة | الدليل |
|---|---|---|---|
| SA-13 | تصنيف بعض ملفات Webpack المجمعة `UNKNOWN_NOT_VERIFIED` | **تم الإصلاح على مستوى المحلل** | `classify(data, filename=...)` يتعرف على حزم Webpack ويقبل امتداد JS بعد رفض HTML/WAF/JSON/الملفات الثنائية |
| SA-14 | فحص `--local` لا يجتاز المجلدات الفرعية ويخلط الملفات متشابهة الاسم | **تم الإصلاح على مستوى المحلل** | `iter_source_files` و`collect_records` مع `relative_path`، تجاوز الروابط الرمزية واستبعاد مجلدات البناء الشائعة |
| SA-15 | عدم اكتشاف `/api/verify/` في مسار DMS | **تم الإصلاح على مستوى المحلل** | `PAT_DMS_API` و`PAT_XHR_DMS_CALL` يستخرجان مسار API وطلب XHR من نسخة DMS المصغرة |

## حماية أداة التحليل

- حدّ أقصى **3000 ملف** في فحص واحد، مع `MAX_SIZE` موجود مسبقًا وهو 12MB للملف.
- دعم `.js` و`.mjs` و`.cjs` و`.html` في تحليل المجلدات المحلية.
- فحص المحتوى لتمييز HTML/WAF/JSON/الملفات الثنائية عن JavaScript قبل الاستدلال من الامتداد.
- لا تتبع الروابط الرمزية، ولا تدخل `.git` أو `node_modules` أو `reports` أو `__pycache__` أو `.venv`.
- يحتفظ JSON وCSV والتقرير HTML والمسارات النصية باسم المسار النسبي، حتى لا تندمج ملفات مختلفة تحمل الاسم نفسه.

## الاختبارات المنفّذة

- تمت إضافة **8 اختبارات انحدار** إلى 3 اختبارات سابقة، ليصبح الإجمالي **11 اختبارًا** في `tests/test_audit.py`.
- أُضيف اختبار تكامل في GitHub Actions ينفّذ `python analyze.py --local research` على أرشيف المصدر الموجود داخل المستودع فقط، ثم يتحقق من ملفات QR ومسارات UBOOR وDMS.
- آخر GitHub Actions الذي راجعناه: [نجاح الاختبارات](https://github.com/abdulstarzeki001-sketch/Star-Cyber-Audit-iSH/actions/runs/42384311890) على commit `5b4da0c00fbe825b2d96995017da2b414a0467b2`.
- هذا اختبار ثابت **لا يستدعي مواقع حكومية عبر الشبكة** ولا ينفّذ JavaScript المرفوع.

## التشغيل الآن

```sh
git pull
python3 -m unittest discover -s tests -v
sh run.sh --local ./research
cat reports/api_paths.txt
```

يعمل الفحص المحلي على iSH وLinux. خيار `--fetch` أو `--fetch-all` منفصل ويحتاج إلى طلب المستخدم؛ اختبار CI لا يستخدمه.

## الملاحظات التي لا تزال مفتوحة

**لم تُعدّل الشيفرات الحكومية المؤرشفة**: ما زال ملف `QRLocal` يحوي Console logging للتوكن وPOST تشخيصيًا؛ و`QRDocument` يحوي fallback غير دقيق عند فقدان ID؛ و`index-gleMzSil` يحتمل أن يخلط رموز الموظف/صاحب الشركة في Axios؛ وتبقى مشكلة دلالة QR البصري مقابل الاعتماد الرسمي.

تتطلب هذه البنود تعديلًا داخل تطبيق الجهة المالكة ومراجعة من فريقها المخوّل. وجودها في التقرير لا يثبت تجاوز مصادقة أو صحة وثيقة.

**Cloudflare:** لم نغير كود Worker أو نشر الموقع أثناء هذا الإصلاح؛ العينة العامة في لوحة الويب لا تتحدث آليًا عند تحديث `analyze.py`.

## ملاحظات هندسية متبقية في المحلل

- التعرف على JS بالامتداد بعد رفض أنواع المحتوى المعروفة هو **استدلال ثابت**، وقد يصنّف نصًا غير قياسي كـJS؛ لا يوجد parser نحوي متكامل.
- اكتشاف المسارات ديناميكيًا أو خلال بناء سلاسل نصية معقدة ليس شاملًا.
- حد 3000 ملف يمنع التوسع غير المنضبط، لكن `os.walk` يجمع أسماء الملفات في كل مجلد؛ ينصح بعدم تمرير مجلدات كبيرة أو غير موثوقة بلا مراجعة.
- لا يوجد تحقق خادمي من توقيعات QR أو APIs في هذه الأداة.

**الخلاصة:** أصلحت تغطية أداة الفحص على الملفات المرفوعة، واجتازت الاختبارات؛ تبقى مراجعة سلوك واجهات الطرف الثالث منفصلة.
