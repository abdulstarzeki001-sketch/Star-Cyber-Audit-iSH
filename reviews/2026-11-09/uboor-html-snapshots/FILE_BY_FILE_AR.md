# تدقيق أربع لقطات HTML من UBOOR وبوابة أصحاب الشركات

**التاريخ:** 9 نوفمبر 2026  
**طريقة العمل:** قراءة ملفات HTML الأربعة المرفوعة، واستخراج عنوان الصفحة وروابط JS/CSS وحالة العرض بعد Vue hydration، ثم مقارنة الأصول المشار إليها مع الملفات الموجودة في المستودع. **لم نحمّل الأصول المشار إليها ولم نجرِ أي اتصال بواجهات حكومية.**

**سياسة الخصوصية:** أول اسم رفع يتضمن قيمة طويلة شبيهة برمز التحقق/الجلسة؛ ولقطتان تحتويان على بريد/هاتف أو بيانات شخصية في DOM. حفاظًا على الخصوصية، لا نرفع ملفات HTML الأصلية، ولا ننقل الاسم الطويل، أو أي رقم هاتف، أو بريد، أو رمز، أو قيمة Hash Code، إلى GitHub. نستخدم فقط الأسماء المحايدة H01–H04.

## H01 — لقطة خطأ التحقق من صاحب الشركة

- **الحجم:** 19,185 بايت. **العنوان:** «بوابة أصحاب الشركات».
- **أصل التشغيل:** `../assets/index-ccmhdhtn.js`، مع preload لـ`companyownerview-cjdszkn6.js`.
- **CSS:** `../assets/index-dxnlxmd6.css`، ومكونات BaseModal وCompanyOwnerView والتصميم المشترك.
- **حالة DOM المحفوظة:** رسالة «حدث خطأ أثناء التحقق من صاحب الشركة» مع «خطأ في السيرفر»؛ ثم شاشة «تسجيل الدخول عبر بوابة أور» وزر «دخول».
- **الدلالة:** الواجهة عرضت نتيجة فشل تحقق في هذه اللحظة. لا يكفي ذلك لتحديد السبب أو كود HTTP، ولا للحكم هل كان بسبب انتهاء رمز أو خطأ خادم أو اختلاف جلسة.
- **حماية:** وجود رمز في اسم ملف الرفع لا يثبت صحته أو قابلية إعادة استخدامه، ويجب عدم تداوله علنًا.

## H02 — لقطة شاشة صاحب الشركة بعد الوصول إلى البحث

- **الحجم:** 21,241 بايت. **العنوان:** «بوابة أصحاب الشركات».
- **نفس أصول H01 بالضبط:** `index-ccmhdhtn.js` و`companyownerview-cjdszkn6.js` وCSS المرتبط بهما.
- **حالة DOM المحفوظة:** قسم صاحب الشركة، بطاقة تحتوي بيانات تواصل شخصية، وحقل نصي يطلب «كود الشركة (Hash Code)» الوارد عبر SMS وزر «بحث».
- **الدلالة:** هذه **واجهة بحث عن الشركة**، ولم يظهر في اللقطة مستند شحن مؤقت أو قائمة مواد أو نتيجة `company_item_reduce`.
- **الحدود:** ظهور اسم/بريد/هاتف في HTML يدل على وجودها في DOM المحفوظ، ولا يثبت وحده عملية تحقق خادمية حالية أو امتلاك جلسة نشطة. كذلك لا نعرف من هذه اللقطة كيف يُتحقق من كود الشركة في Backend.
- **الخصوصية:** لا تُدرج بيانات صاحب الشركة أو رقم الهاتف أو البريد في هذا التقرير.

## H03 — الصفحة الرئيسية العامة UBOOR TECH

- **الحجم:** 19,436 بايت. **العنوان:** «الرئيسة».
- **أصل التشغيل:** `assets/index-cseaomal.js` و`assets/index-iqgxgunl.css`.
- **حالة DOM المحفوظة:** الصفحة الرئيسية تعرّف بمنصة UBOOR TECH ونظام TIR وتتبع شحنات العبور، مع خيار «تسجيل الدخول» وروابط الدليل والتواصل.
- **مهم:** هذه ليست شاشة شركة بعينها ولا صفحة إصدار PDF. لا تحتوي طلبات API تنفيذية في HTML نفسه؛ المنطق البرمجي في `index-cseaomal.js` غير المرفق.
- **الخصوصية:** احتوت لقطة الصفحة على بيانات تواصل ظاهرة. لا تعاد طباعتها في المستودع.

## H04 — واجهة تسجيل دخول UBOOR TECH

- **الحجم:** 19,581 بايت. **العنوان:** «تسجيل الدخول».
- **أصل التشغيل:** `../assets/index-cseaomal.js`، وpreload لـ`../assets/loginview-czys-bdx.js` مع `form-o25ckf6s.js` و`formfield-dm6xmaiy.js` و`input-ce30asl_.js` و`schemas-b4dorvt-.js`.
- **حالة DOM المحفوظة:** نموذج فيه `input[type=text]` لاسم المستخدم، و`input[type=password]` لكلمة المرور، وزر «دخول».
- **لا توجد بيانات تسجيل دخول ظاهرة** في هذا النموذج المحفوظ. لكن وجود `type=password` ليس دليلًا على سياسة المصادقة، أو طريقة تخزين كلمات المرور، أو واجهة طلب تسجيل الدخول.
- **الحدود:** لا يمكن معرفة API تسجيل الدخول أو أخطاء التحقق أو رمز المصادقة من هذا HTML وحده؛ يلزم ملف `loginview-czys-bdx.js` وملف البناء `index-cseaomal.js`.

## مقارنة البناءين

| وجه المقارنة | صفحات أصحاب الشركات H01/H02 | UBOOR TECH H03/H04 |
|---|---|---|
| مدخل JS | `index-ccmhdhtn.js` | `index-cseaomal.js` |
| المكوّن المسبق | `companyownerview-cjdszkn6.js` | `loginview-czys-bdx.js` في H04 |
| CSS الرئيسي | `index-dxnlxmd6.css` | `index-iqgxgunl.css` |
| وظيفة اللقطات | تسجيل/تحقق أور، كود الشركة | صفحة تعريف عامة، واسم مستخدم/كلمة مرور |
| حالة التوثيق | مكوّن CompanyOwnerView موجود في الأرشيف | ملف LoginView المشار إليه غير موجود |

**فرق حاسم:** تكرار عنوان الصفحة أو اسم المؤسسة ليس إثباتًا أن البناءين يستخدمان نفس Backend أو نفس آلية توقيع QR. ومن H01/H02 يمكن إثبات وجود **حالتين مرئيتين مختلفتين** فقط، لا تسلسل زمني خادمي مؤكد بينهما.

## الربط بمراجعات الملفات السابقة

- `companyownerview-cjdszkn6.js` **مؤرشف مسبقًا** في [مجلد owner-vite](../../../../research/raw-uploads/2026-11-07/company-owner-vite/companyownerview-cjdszkn6.js). هذا مكوّن مختلف عن `CompanyOwnerView-CIdFF3LL.js` الذي حللناه في بناء آخر.
- `index-dxnlxmd6.css` **مؤرشف مسبقًا** أيضًا.
- `index-ccmhdhtn.js` **غير موجود** في المستودع وقت المراجعة؛ ورود اسمه داخل `<script src>` لا يعني أننا استلمنا محتواه.
- `index-cseaomal.js` و`loginview-czys-bdx.js` **غير موجودين** أيضًا.
- الفحص السابق لمسار `ShipmentDoc` والوثيقة المؤقتة لا يتغير بمجرد ظهور نموذج الدخول في H01/H02؛ نحتاج JS المستعمل في هذا البناء لتعقب تدفقه الفعلي.

## قائمة الملفات الأكثر فائدة في الدفعة القادمة

1. **`index-ccmhdhtn.js`** — الأولوية الأولى لتحديد store والتوجيه وربط بوابة صاحب الشركة الجديدة.
2. **`index-cseaomal.js`** — مقارنة تطبيق UBOOR TECH العام وآلية تسجيل الدخول مع الحزمة `index-gleMzSil.js` التي لدينا.
3. **`loginview-czys-bdx.js`** — منطق نموذج اسم المستخدم/كلمة المرور والتحقق من الحقول.
4. **`basemodal-c8lwmuhw.js`** — نافذة بناء أصحاب الشركات الآخر، وقد تختلف عن `BaseModal-DjCaQzje.js`.
5. **`schemas-b4dorvt-.js`** — schema التحقق من حقول تسجيل الدخول.

اطلب أو انقل **ملفات JavaScript العامة فقط**؛ لا ترسل توكنات جلسات أو كلمات مرور أو روابط تحقق شخصية، ولا تنشر HTML يحتفظ ببيانات العملاء.

## خلاصة الحدود

هذه **لقطات DOM بعد تحميل Vue**؛ لا يمكن منها إثبات صلاحية QR، أو إتمام المصادقة، أو توثيق إصدار PDF مؤقت، أو وجود تجاوز تفويض في Backend. التقرير والسجل [manifest.json](manifest.json) هما الإضافة الجديدة إلى GitHub، **ولم تُنشر الملفات الأربعة الخام**.
