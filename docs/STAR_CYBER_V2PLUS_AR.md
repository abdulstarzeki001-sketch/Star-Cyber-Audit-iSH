# Star Cyber Audit V2+ — محرك فحص الشيفرة الحقيقي

الفرق الأساسي عن V2: أصبح المتصفح يقرأ ملفات الشيفرة مباشرة ويفحصها محليًا، بدلاً من الاكتفاء بعرض تقارير محفوظة. هذه نسخة مراجعة ساكنة (Static Analysis)، لا فحص اختراق حي ولا نظام AI مستقل.

## القدرات
- اختيار ملفات `.js` و`.ts` و`.tsx` و`.jsx` و`.py` و`.html` وغيرها من صيغ الشيفرة المحددة.
- استخراج المسارات المرجعية وبعض الاستيرادات ومفاتيح التخزين.
- تحديد 8 قواعد أمنية تجريبية ومؤشرات مفاتيح حساسة (لا تعرض القيم).
- عرض مستوى خطورة إرشادي لكل ملف (0-100) لا يعتبر معيار CVSS ولا ضمانًا لوجود ثغرات.
- إظهار اسم الملف والسطر والتوصية، وبصمة SHA-256.
- تصدير `analysis.json` محليًا؛ يمكن استيراده في مستكشف النتائج الموجود في V2.

## الخصوصية
ملفات المستخدم تُقرأ من File API في متصفح الجهاز وتُحلل محليًا فقط. لا تُرسل إلى Cloudflare أو إلى OpenAI؛ لا يتم تنفيذ الشيفرة أو الاتصال بالخوادم المستهدفة. سياسة CSP تحدد `connect-src 'none'` وتحظر النصوص البرمجية المضمنة.

حدود: 32 ملفًا، 2 MiB للملف الواحد، 16 MiB للإجمالي. السطور التي تتجاوز 8192 حرفًا تُقص أثناء تطبيق قواعد الأسطر لتجنب تجميد الآيفون؛ تُعرض قيمة `clipped_lines` ويجب عدم اعتبار غياب النتائج دليلًا على الأمان. نتائج Regex استدلالية وليست تحليل تدفق بيانات كاملًا.

## تشغيل الفحوص والاختبارات
```sh
node --check site/source-analysis-core.mjs
node --check site/source-engine-ui.mjs
node --check site/worker-v2plus.mjs
node tests/source_engine_v2.test.mjs
node tests/worker_v2plus.test.mjs
```

## البنية
- `site/source-analysis-core.mjs`: محرك التحليل النقي، قابل للاختبار منفصلًا.
- `site/source-engine-ui.mjs`: واجهة اختيار الملفات وتصدير النتائج.
- `site/source-engine.css`: تنسيق متجاوب.
- `site/worker-v2plus.mjs`: Worker منفصل يقدّم واجهة V2 الأصلية مع أصول التحليل الجديدة.
- `tests/*v2*.test.mjs`: اختبارات AST محدودة/regex ومسارات HTTP.
- `.github/workflows/v2plus-source-engine.yml`: CI مستقل.

## طريقة التطوير الجدي التالية
الترقية بعد هذا الإصدار ينبغي أن تكون محرك AST فعليًا (مثل Tree-sitter أو Semgrep/CodeQL على آلة Linux مخولة)، ومهام متعددة العمال، وتاريخ أدلة موثق، وتكامل GitHub PRs، وربط AI باستخدام RAG خاص بالمستودع وموافقات صريحة قبل أي عملية نشر. **هذه القدرات ليست موجودة بمجرد نشر هذه الواجهة.**

احتفظ بـ V1 وV2 دون تغيير؛ انشر V2+ على Worker منفصل. لا يُنصح برفع ملفات تحتوي بيانات شخصية أو حساسة إلى أي خدمة سحابية أخرى.
