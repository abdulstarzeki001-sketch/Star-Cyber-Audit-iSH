# STAR AI — مساعد مشروع Star Cyber Audit على iSH

هذه إضافة **غير مدمّرة** إلى المشروع الخاص. تعمل عبر Python القياسي بلا حزم AI إلزامية، وتفهرس الوثائق وأدوات المشروع المحلية فقط. **لا تقوم بفحص مواقع حية، ولا تعطي صلاحيات تحكم عن بُعد في الآيفون، ولا تنشئ مفاتيح OpenAI تلقائيًا.**

## التشغيل المحلي على iPhone / iSH

افتح مجلد المشروع الموجود لديك (ويجب أن يحتوي `run.sh`). إذا كان مثبتًا داخل `/mnt/star-audit`:

```sh
apk add python3 ca-certificates
cd /mnt/star-audit
python3 tools/ish/star_ai.py doctor
python3 tools/ish/star_ai.py index
python3 tools/ish/star_ai.py ask "اشرح QRDocument وقيود التحقق"
python3 -m unittest discover -s tests -v
sh run.sh --local research
```

**مهم:** إذا كنت تستخدم النسخة المحلية القديمة، حدّثها أولًا من GitHub بالطرق التي تستخدمها بالفعل، أو انسخ الملفات الجديدة من فرع الـPR بعد دمجه. لا تفترض أن تحديث GitHub ينتقل إلى iSH آليًا.

الوضع الافتراضي **بحث محلي فقط**: يعرض مقتطفات من ملفات المشروع مع مساراتها وأرقام الأسطر؛ **ليس توليدًا بنموذج AI**، ولا يحتاج إنترنت أو مفتاح API. يتجاهل ملفات البحث الخام، التنزيلات، التقارير الناتجة، `.env` والمفاتيح. هذه ليست آلية DLP شاملة.

## تشغيل إجابة مولدة عبر OpenAI (اختياري)

تحتاج حساب API منفصلًا وصلاحية استخدام نموذج من OpenAI؛ اشتراك ChatGPT ليس مفتاح API. راجع: https://platform.openai.com/api-keys

ضع `OPENAI_API_KEY` كمتغير بيئة في جلسة آمنة، ولا تكتبه في مستودع GitHub، أو الأوامر التي يحفظها السجل، أو صور الشاشة. اختر اسم نموذج متاح فعليًا في حسابك:

```sh
export OPENAI_MODEL="YOUR_AVAILABLE_MODEL_ID"
python3 tools/ish/star_ai.py ask "ما حدود تحليل QR؟" --cloud --allow-cloud-context
```

البرنامج يرفض `--cloud` وحدها، ويطالب أيضًا بـ `--allow-cloud-context` (إقرار واعٍ بأن المقتطفات سترسل إلى OpenAI). يقتطع عددًا محدودًا من المقاطع، ويخفي أنماطًا شائعة مثل مفاتيح API وBearer tokens والبريد والكوكيز. **قد تفلت بيانات حساسة من التنقيح الآلي**، لذلك استخدم الوضع المحلي للمحتوى الحكومي أو السري، وراجع مصادر الاسترجاع قبل تمكين الإرسال. يرسل الطلب عبر HTTPS إلى `/v1/responses` مع `store: false` ويطبع الإجابة دون حفظها في مستودعك. استخدام API قد يُكلف رسومًا مستقلة.

## العمل البرمجي الكامل باستخدام ChatGPT / Codex

- اربط **المستودع الخاص** ببيئة Codex أو Work التي تملك صلاحية GitHub؛ ملف `AGENTS.md` يحدد مهمة الوكيل وضوابط التنفيذ.
- اطلب مراجعة `analyze.py` و`tools/ish/`، أو تنفيذ تعديل على فرع مستقل، ثم تشغيل الاختبارات وفتح Pull Request.
- يجب استخدام ملفات الأرشيف الموجودة داخل نطاق المشروع؛ لا توسع الفحص إلى البوابات الحكومية الحية دون موافقة ونطاق اختبار صريحين.
- لا تمنح النموذج مفاتيح الإنتاج أو وصولًا عامًا لحاسوبك. نفّذ أي أوامر iSH من جلسة محلية تراجعها بنفسك؛ ChatGPT لا يملك وصولًا مباشرًا تلقائيًا إلى شاشة iPhone.

## التحقق والصيانة

```sh
python3 -m py_compile analyze.py tools/ish/star_ai.py
python3 -m unittest discover -s tests -v
sh -n run.sh
```

GitHub Actions يشغّل `unittest discover` في Pull Requests، ومن ضمنها اختبارات المساعد الخاصة بالعزل، عدم اتصال الوضع المحلي بالشبكة، تنقيح البيانات، ومنع الرفع غير المقصود. راجع تقرير CI قبل دمج الفرع.
